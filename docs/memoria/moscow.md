**Data:** 2026-03-13
**Aprovado por:** netol

## 📦 MUST HAVE — Primeira Versão

- [ ] Cadastro de cliente (auth por telefone + OTP)
- [ ] Cadastro de profissional (auth por telefone + OTP)
- [ ] Verificação de profissional (CPF/CNPJ + upload de documento)
- [ ] Perfil do profissional (foto, descrição, categorias, cidade de atuação)
- [ ] Publicar pedido — Modo Tarefa (micro-tarefa rápida)
- [ ] Publicar pedido — Modo Profissional (serviço especializado)
- [ ] Profissional visualiza feed de pedidos por categoria e região
- [ ] Revelar contato do cliente (telefone/WhatsApp — gratuito na v1)
- [ ] Notificações push (novo pedido na categoria do profissional)
- [ ] Sistema de avaliações (estrelas 1-5 + comentário)
- [ ] Filtro por estado do Nordeste (9 estados)
- [ ] 10 categorias de serviço + Tarefas Rápidas
- [ ] Pedido expira automaticamente após 48h

## 📦 SHOULD HAVE — Logo Depois (v1.1)

- [ ] Portfolio do profissional (fotos de trabalhos anteriores)
- [ ] Chat in-app (mensagens sem sair para WhatsApp)
- [ ] Histórico de pedidos (cliente e profissional)
- [ ] Busca por nome de serviço

## 📦 COULD HAVE — Se Der Tempo (v2)

- [ ] Sistema de moedas/comissão (motor financeiro)
- [ ] Painel admin web (moderar, verificar, banir)
- [ ] Programa de indicação (profissional indica e ganha benefício)
- [ ] Métricas para o profissional (visualizações, taxa de conversão)

## 📦 WON'T HAVE — Futuro

- [ ] Pagamento in-app / gateway de pagamento

- [ ] Expansão fora do Nordeste

- [ ] Seguros e garantias de serviço
